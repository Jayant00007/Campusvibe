# Campus Vibe Fest 2026

A small college fest website made using HTML and CSS.

## Features
- Fest name, date and venue
- Five event details
- Event schedule table
- Organiser and sponsor details
- Registration form
- Responsive layout and a simple CSS animation

## Run
Open `index.html` in a web browser.

Note: The registration form is a front-end demo. It does not store submissions.
